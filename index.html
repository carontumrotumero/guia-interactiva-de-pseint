Qué es PSeInt y estructura de un algoritmo

PSeInt es un intérprete de pseudocódigo en español. Permite escribir algoritmos con palabras en castellano (Escribir, Leer, Si, Mientras...) sin la sintaxis estricta de un lenguaje real, ideal para aprender lógica de programación.

Estructura básica de todo algoritmo:

Algoritmo NombreDelAlgoritmo
	// instrucciones aquí
FinAlgoritmo
  • Algoritmo NombreDelAlgoritmo: marca el inicio. El nombre no puede llevar espacios ni empezar por números.
  • FinAlgoritmo: marca el final del programa.
  • Entre medias van las instrucciones, con sangría (tabulación) para que se lea mejor.
💡

Nota: La mayoría de ejercicios se organizan en tres fases claras: ENTRADA (pedir datos al usuario), PROCESO (calcular o transformar) y SALIDA (mostrar resultados por pantalla).

2

Variables y tipos de datos

Una variable es una "caja" con nombre en la memoria donde el programa guarda un dato que puede cambiar. Se declara al principio con la palabra clave Definir, indicando el nombre de las variables y su tipo: 

Definir nota1, nota2, suma Como Real;
Definir edad Como Entero;
Definir nombre Como Caracter;
Definir esMayor Como Logico;
Tipo Qué guarda Ejemplos
Entero Números exactos sin decimales 5, -3, 100, 0
Real Números con decimales (usan punto .) 7.5, 3.14, -2.0
Caracter Texto, letras o palabras entre comillas "Hola", "Juan", "A"
Logico Valores booleanos (verdadero o falso) Verdadero, Falso
⚠️

Nota: Si declaras una variable como Entero y el usuario introduce un decimal o una división da decimales, dará error de ejecución. Para notas, precios, medias o alturas siempre se usa Real.

3

Asignación (<-) frente a Comparación (=)

Es fundamental no confundir guardar un valor con preguntar si dos valores son iguales:

Asignación: <-

La flecha <- significa "guarda en". Se lee de derecha a izquierda: primero se calcula la expresión de la derecha y el resultado se guarda en la variable de la izquierda. 

suma <- nota1 + nota2;
contador <- contador + 1;

Comparación: =

El signo igual = sirve para preguntar si dos cosas son iguales dentro de una condición (Si, Mientras...). No modifica la variable. 

Si edad = 18 Entonces
	Escribir "Tienes justo 18 años";
FinSi
4

Entrada y Salida de datos (Escribir y Leer)

Para comunicarnos con el usuario utilizamos dos instrucciones fundamentales:

  • Escribir: muestra mensajes de texto (entre comillas) o el valor de variables por pantalla. Se pueden unir textos y variables separándolos con comas (,).
  • Escribir Sin Saltar: muestra el texto sin hacer salto de línea al final (el cursor se queda en la misma línea).
  • Leer: detiene el programa, espera a que el usuario escriba un dato por teclado y lo guarda en la variable indicada.
Algoritmo EjemploEntradaSalida
	Definir nombre Como Caracter;
	Definir edad Como Entero;
	
	Escribir Sin Saltar "Introduce tu nombre: ";
	Leer nombre;
	
	Escribir "Introduce tu edad: ";
	Leer edad;
	
	// Unimos texto y variables usando comas
	Escribir "Hola ", nombre, ", tienes ", edad, " años.";
FinAlgoritmo

6

Condicionales: Si - Entonces - SiNo

Permite que el programa tome decisiones. Si la condición es Verdadera, ejecuta el bloque tras Entonces. Si es Falsa, ejecuta el bloque tras SiNo (el bloque SiNo es opcional). También se pueden anidar unos dentro de otros. 

Algoritmo EjemploCondicional
	Definir nota Como Real;
	Escribir "Introduce tu nota (0 a 10):";
	Leer nota;
	
	Si nota >= 5 Entonces
		Escribir "¡Has aprobado!";
	SiNo
		Escribir "Has suspendido. Toca recuperar.";
	FinSi
FinAlgoritmo
7

Condicional múltiple: Según (Switch)

Cuando tenemos que evaluar muchos valores exactos de una misma variable numérica (por ejemplo, un menú de opciones o los días de la semana del 1 al 7), Segun es mucho más limpio que encadenar muchos Si. Si el valor no coincide con ningún caso, se ejecuta De Otro Modo. 

Algoritmo EjemploSegun
	Definir opcion Como Entero;
	Escribir "Menú: 1. Sumar | 2. Restar | 3. Salir";
	Leer opcion;
	
	Segun opcion Hacer
		1:
			Escribir "Has elegido Sumar";
		2:
			Escribir "Has elegido Restar";
		3:
			Escribir "Saliendo del programa...";
		De Otro Modo:
			Escribir "Error: opción no válida";
	FinSegun
FinAlgoritmo
8

Bucle Mientras (While)

Repite un bloque de instrucciones mientras la condición sea Verdadera. Como evalúa la condición antes de entrar, si al principio la condición ya es falsa, no se ejecutará ni una sola vez. 

Algoritmo EjemploMientras
	Definir i Como Entero;
	i <- 1; // 1. Inicializar variable de control
	
	Mientras i <= 5 Hacer // 2. Condición de permanencia
		Escribir "Número: ", i;
		i <- i + 1; // 3. Avanzar para evitar un bucle infinito
	FinMientras
FinAlgoritmo
9

Bucle Repetir - Hasta Que (Do-While)

A diferencia de Mientras, este bucle evalúa la condición al final, por lo que sus instrucciones se ejecutan como mínimo una vez. Además, se repite mientras la condición sea Falsa y se detiene cuando la condición de Hasta Que se cumple. Es ideal para validar datos de entrada o contraseñas. 

Algoritmo ValidarNotaPositiva
	Definir nota Como Real;
	
	Repetir
		Escribir "Introduce una nota válida (entre 0 y 10):";
		Leer nota;
	Hasta Que nota >= 0 Y nota <= 10
	
	Escribir "Nota registrada correctamente: ", nota;
FinAlgoritmo
10

Bucle Para (For)

Se utiliza cuando sabemos de antemano cuántas veces exactas queremos repetir algo. Él mismo inicializa la variable contadora y la incrementa automáticamente en cada vuelta (Con Paso 1 por defecto, o Con Paso -1 para cuenta atrás). 

Algoritmo EjemploPara
	Definir i Como Entero;
	
	// Cuenta del 1 al 5 sumando de 1 en 1
	Para i <- 1 Hasta 5 Con Paso 1 Hacer
		Escribir "Vuelta número: ", i;
	FinPara
FinAlgoritmo

Contadores y Acumuladores

Son variables normales que se usan dentro de los bucles con un propósito especial. Siempre deben inicializarse (normalmente a 0) antes del bucle:

Contador (suma una cantidad fija)

Sirve para contar cuántos elementos cumplen una condición (ej. cuántos aprobados hay).

cuenta <- 0;
// Dentro del bucle:
cuenta <- cuenta + 1;

Acumulador (suma una cantidad variable)

Sirve para ir sumando totales (ej. la suma de todos los precios o todas las notas).

sumaTotal <- 0;
// Dentro del bucle:
sumaTotal <- sumaTotal + precio;
12

Arreglos o Vectores (Dimension)

Un vector (o arreglo) es una colección de variables del mismo tipo guardadas bajo un único nombre y numeradas por un índice entre corchetes [i]. En PSeInt (configuración estándar), las posiciones empiezan en 1. Se crean con la palabra clave Dimension y se recorren casi siempre con un bucle Para. 

Algoritmo EjemploVector
	Definir datos, i Como Entero;
	Dimension datos[5]; // Crea un vector con 5 casillas (datos[1] a datos[5])
	
	Para i <- 1 Hasta 5 Con Paso 1 Hacer
		Escribir "Introduce el valor para la casilla ", i, ":";
		Leer datos[i];
	FinPara
FinAlgoritmo

Funciones integradas útiles (Matemáticas y Texto)

PSeInt incluye funciones listas para usar con números y cadenas de caracteres:

Función Descripción Ejemplo y Resultado
rc(x) / raiz(x) Calcula la raíz cuadrada de x rc(16) -> 4
abs(x) Valor absoluto (quita el signo negativo) abs(-8) -> 8
trunc(x) / redon(x) Quita los decimales / Redondea al entero más cercano trunc(4.8) -> 4 | redon(4.8) -> 5
azar(n) / Aleatorio(a,b) Genera entero al azar entre 0 y n-1 / o entre a y b Aleatorio(1, 10)
Longitud(texto) Devuelve cuántas letras tiene una palabra Longitud("Hola") -> 4
Subcadena(txt, ini, fin) Extrae caracteres desde la posición ini hasta fin Subcadena("Hola", 1, 1) -> "H"
Mayusculas(t) / Minusculas(t) Convierte todo el texto a mayúsculas o minúsculas Mayusculas("abc") -> "ABC"
